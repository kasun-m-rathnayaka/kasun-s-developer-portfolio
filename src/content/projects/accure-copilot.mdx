## Problem

Accure users needed AI help inside the product, not in a separate chat tool, and the team needed to see who was using AI and how much.

## What I built

A slide-out assistant with a model selector, prompt templates, a code diff viewer, message persistence and custom content modes. Alongside it, a token consumption dashboard tracking Accure Copilot and Accure AI usage per tenant, per user and per application, with daily trends. I also researched agentic workflows for client onboarding.
