## Problem

AWE ran a core process in Excel, which was slow to update and hard to share.

## What I built

A web dashboard that replaced the spreadsheet, with real-time charts and automated workflow steps, on Next.js, React Query and MongoDB behind a REST API.

## Outcome

The Excel-based process is now a web dashboard with real-time charts and automated workflow steps, so updates are quicker and results are easy to share.
